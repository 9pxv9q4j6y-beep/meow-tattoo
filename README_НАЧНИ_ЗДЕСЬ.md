# MEOW TATTOO — рабочий сайт

Это автономная (без сборки/серверной части) версия сайта MEOW TATTOO. Всё содержимое уже включено в папку.

## Как запустить без VS Code на MacBook
1. Распакуйте ZIP.
2. Откройте папку MEOW-TATTOO-FINAL.
3. Дважды нажмите `index.html`. В Safari или Chrome откроется сайт. Интернет нужен только для переходов в Telegram, VK, карты и загрузки веб-шрифтов.
4. Не выносите `index.html` из папки: изображения и файлы должны остаться рядом.

## Как открыть на iPhone
Локальный ZIP на телефоне неудобен для полноценного теста. Загрузите всё содержимое папки (index.html, style.css, script.js и папку assets) в репозиторий GitHub и включите GitHub Pages в Settings → Pages → Deploy from a branch → main → / (root). Затем откройте полученную ссылку в Safari. Не публикуйте в действующем репозитории без резервной копии.

## Что работает
- Интерактивная комната с кликабельными объектами.
- Кошка с тремя позами и перемещением.
- Три карточки мастеров: по 7 фото тату у Ксении и Элины; у Карины — 8 новых фото пирсинга вместо прежних работ, новая портретная фотография и ссылка на группу пирсинга VK.
- Тату-прайс и полные отдельные прайсы на пирсинг Карины и Элины.
- Портфолио пирсинга Карины (8 новых фотографий). У Элины фотографий пирсинга не было, поэтому фото ей не приписаны.
- Галерея пяти обработанных фотографий студии в единой бордово-неоновой стилистике.
- Скечбук: 6 свободных эскизов Ксении, плавное листание, увеличение, специальная цена 2500 ₽ за размер до 5 см.
- Шуточное Таро Элины с 30 случайными предсказаниями.
- Контакты, адрес, возрастные правила.
- Мобильный обзор комнаты + зум и удобные большие карточки.

## Контент и сохранность
Фотографии работ и эскизов не перерисованы, файлы обработаны только для экономии трафика. Фото студии заменены на ранее подготовленные стилизованные версии; детали могут немного отличаться от исходников. Фотографии пирсинга Карины не перерисовывались. Тексты подготовлены для сайта по предоставленной информации.

В разделе пирсинга указано, что украшения оплачиваются отдельно у обоих мастеров. Информация о предоплате и памятках по уходу по просьбе владельца на сайте отсутствует.

Перед публичной публикацией убедитесь, что все люди на фотографиях согласны на использование снимков на сайте.

Контент можно менять в `script.js`; адреса файлов фото — в `assets/`. Цены приведены из присланных фотографий прайсов.

## Как позже обновлять свободные эскизы
Текст больше не упоминает фиксированное число эскизов. В файле `script.js` список `flashTitles` определяет число страниц, которое автоматически показывается счётчиком альбома; соответствующие изображения лежат в `assets/flash-1.webp`, `flash-2.webp` и т. д. Чтобы добавить эскиз, добавьте изображение и название в этот список. При удалении середины последовательности перенумеруйте файлы.
